# 📊 Superstore Sales & Profit Dashboard

## 📌 Project Overview

This project was created as part of the Data Analyst Internship – Task 2: Data Visualization and Storytelling.

The objective was to transform raw Superstore sales data into an interactive Power BI dashboard that provides clear insights into sales, profit, quantity, regions, categories, and states.

## 🎯 Objectives

- Analyze sales performance over time
- Compare sales across different regions
- Analyze category-wise sales and profit
- Visualize sales distribution by state
- Highlight important KPIs
- Create an interactive and easy-to-understand dashboard

## 🛠️ Tools Used

- Power BI
- Superstore Dataset

## 📊 Dashboard Features

### KPI Cards
- Total Sales
- Total Profit
- Total Quantity

### Visualizations
- Sales Trend by Year
- Sales by Region
- Sales by Category
- Profit by Category
- Sales by State using Map

### Interactive Filters
- Category Filter
- Region Filter

## 📈 Visualization Choices

- **Line Chart:** Used to show sales trends over the years.
- **Bar Charts:** Used to compare sales and profit across categories and regions.
- **Map:** Used to show geographic distribution of sales by state.
- **KPI Cards:** Used to highlight important business metrics.
- **Slicers:** Used to filter the dashboard interactively.

## 💡 Key Insights

The dashboard helps identify:

- Year-wise sales trends
- Regional sales performance
- Category-wise sales performance
- Category-wise profit
- Geographic distribution of sales
- Overall sales, profit, and quantity
