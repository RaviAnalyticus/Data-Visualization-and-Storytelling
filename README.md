Task 2: Data Visualization and Storytelling
📊 Superstore Sales & Profit Dashboard
This project was created as part of the Data Analyst Internship – Task 2: Data Visualization and Storytelling.
The objective of this task was to create meaningful visualizations and present sales data through an interactive Power BI dashboard.
🛠️ Tools Used
Power BI – Dashboard creation and data visualization
Superstore Dataset – Sales data analysis
📌 Dashboard Features
The dashboard includes:
Total Sales KPI
Total Profit KPI
Total Quantity KPI
Sales Trend by Year
Sales by Region
Sales by Category
Profit by Category
Sales by State map
Category Filter
Region Filter
📈 Key Visualizations
The dashboard uses different charts according to the type of information being presented:
Line Chart → Analyze sales trends over the years
Bar Charts → Compare sales and profit across categories and regions
Map Visualization → Analyze sales distribution by state
KPI Cards → Highlight important business metrics
Slicers → Allow users to interactively filter the dashboard
🎯 Objective
The main objective of this dashboard is to transform raw sales data into an easy-to-understand visual report that helps identify:
Sales performance over time
Regional sales performance
Category-wise sales
Category-wise profit
Geographic distribution of sales
Overall sales, profit, and quantity
