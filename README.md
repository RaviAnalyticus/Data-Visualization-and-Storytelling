📌 Project Overview
This project is part of the Data Analyst Internship (Task 2). The goal was to build meaningful visualizations and present sales data through an interactive Power BI dashboard, so that business users can explore performance without touching the raw data.
🎯 Objectives
The dashboard is designed to help identify:
Sales performance over time
Regional sales performance
Category-wise sales
Category-wise profit
Geographic distribution of sales
Overall sales, profit, and quantity

💡 Key Insights
Using the filters and charts, the dashboard makes it easy to spot patterns in:
Time — how sales have moved year over year
Region — which regions lead or lag in sales
Category — which categories bring in the most sales vs. the most profit
Geography — which states drive the highest sales
